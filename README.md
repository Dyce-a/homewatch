# HomeWatch: умный дом Яндекса на Galaxy Watch

У меня дома свет, кондиционер и розетки управляются через Алису, а на руке Galaxy Watch 8
Classic. Официального приложения умного дома Яндекса для Wear OS нет, и каждый раз
доставать телефон, чтобы выключить свет в коридоре, надоело. Поэтому я написал своё.

HomeWatch показывает все устройства умного дома по комнатам, как в приложении Яндекса,
и даёт управлять ими прямо с часов: включить и выключить, поменять яркость и цветовую
температуру, переключить режим кондиционера, посмотреть температуру и влажность с
датчиков, запустить сценарий или поставить таймер «выключить через 40 минут».

Входишь в аккаунт без клавиатуры: часы показывают QR-код, сканируешь его телефоном,
подтверждаешь вход, и через пару секунд на часах уже список устройств.

## Что умеет

- **Вход по QR-коду.** Часы показывают QR и короткий код, ты подтверждаешь вход на
  телефоне. Токен живёт около года, входить каждый день не нужно.
- **Список устройств по комнатам**, как в приложении Яндекса. Переключатель вкл/выкл
  прямо в списке, тап по устройству открывает экран управления.
- **Управление устройством:** яркость, цветовая температура, режимы (кондиционер,
  вентилятор и т.п.), показания датчиков (температура, влажность).
- **Сценарии** из умного дома запускаются одним тапом.
- **Таймер:** «включить» или «выключить» устройство через выбранное время. Срабатывает,
  даже если приложение закрыто, а часы спят.
- **«Не гасить экран»**, пока открыто приложение, чтобы не будить часы на каждом шаге.
- Навигация свайпом назад, как во всех приложениях Wear OS.

## Стек

- **Kotlin**, Android SDK 34, minSdk 30 (Wear OS 3+)
- **Jetpack Compose for Wear OS**: `wear.compose.material`, `foundation`, `navigation`
- **Корутины** для сетевых запросов и опроса входа
- **OkHttp** для HTTP, без Retrofit: видов запросов всего четыре
- **ZXing** для отрисовки QR-кода прямо на часах
- **AlarmManager** для таймеров, которые переживают закрытие приложения
- **API умного дома Яндекса** (`api.iot.yandex.net/v1.0`) и OAuth Яндекса

## Как это устроено

### Вход

Клавиатуры на часах по сути нет, поэтому вход сделан по схеме OAuth «код на устройстве»
(device flow):

1. Часы просят у `oauth.yandex.ru/device/code` пару кодов: длинный для себя и короткий
   для человека.
2. На экране рисуется QR-код со ссылкой `ya.ru/device` и короткий код.
3. Человек сканирует QR телефоном, входит в свой Яндекс и вводит код.
4. Всё это время часы раз в несколько секунд спрашивают сервер, подтвердили ли вход.
   Как только подтвердили, приходит токен, и часы открывают список устройств.

Токен хранится в `SharedPreferences` приложения. Если API отвечает 401 или 403 (токен
отозвали), приложение само возвращает на экран входа.

### Устройства

Весь дом приходит одним запросом `GET /user/info`: комнаты, устройства, их возможности
(capabilities) и показания (properties). Приложение раскладывает устройства по комнатам
и для каждого понимает, что с ним можно делать: включить, поменять яркость, выбрать режим.
Команда уходит через `POST /devices/actions`, сценарий запускается через
`POST /scenarios/{id}/actions`.

### Таймеры

Таймер ставится через `AlarmManager.setExactAndAllowWhileIdle`, поэтому срабатывает в
нужную минуту, даже если часы в режиме сна. Когда приходит время, `BroadcastReceiver`
сам отправляет команду в API, открытое приложение для этого не нужно. Если точные
будильники запрещены (Android 12+ без разрешения), используется неточный вариант,
который может немного опоздать.

## Структура проекта

```
app/src/main/java/com/ilya/homewatch/
├── MainActivity.kt        навигация между экранами (свайп назад)
├── AppViewModel.kt        состояние: дом, выбранное устройство, таймеры, ошибки
├── Config.kt              ключи OAuth-приложения (берутся из local.properties)
├── DelayedActions.kt      таймеры через AlarmManager + приёмник, который шлёт команду
├── data/
│   ├── AuthRepository.kt  вход по схеме «код на устройстве», хранение токена
│   ├── IotRepository.kt   API умного дома: дом целиком, команды, сценарии
│   ├── Models.kt          комнаты, устройства, возможности
│   └── Net.kt             тонкая обёртка над OkHttp
└── ui/
    ├── AuthScreen.kt      QR-код и короткий код для входа
    ├── HomeScreen.kt      список устройств по комнатам и сценарии
    ├── DeviceScreen.kt    экран управления устройством
    ├── TimerScreen.kt     выбор времени для таймера
    ├── SettingsScreen.kt  «не гасить экран», выход из аккаунта
    ├── QrCode.kt          отрисовка QR через ZXing
    ├── Labels.kt          человеческие названия режимов и типов
    └── Theme.kt           цвета и типографика
```

## Как запустить у себя

### 1. Создать OAuth-приложение Яндекса (5 минут, бесплатно)

Без него Яндекс не пустит приложение в твой умный дом.

1. Зайди на [oauth.yandex.ru](https://oauth.yandex.ru) под тем аккаунтом, где умный дом.
2. Нажми **«Создать приложение»**, название любое, например `HomeWatch`.
3. Платформа: **«Веб-сервисы»**, Redirect URI: `https://oauth.yandex.ru/verification_code`.
4. В «Доступ к данным» найди группу **«Умный дом»** и отметь оба пункта:
   просмотр устройств (`iot:view`) и управление (`iot:control`).
5. Сохрани и скопируй **ClientID** и **Client secret**.

### 2. Положить ключи в local.properties

В корне проекта есть файл `local.properties` (его создаёт Android Studio, в git он не
попадает). Допиши туда две строки:

```properties
yandex.clientId=твой_client_id
yandex.clientSecret=твой_client_secret
```

При сборке они попадут в `BuildConfig`, а в коде и в репозитории их не будет.

### 3. Поставить Android Studio

Скачай с [developer.android.com/studio](https://developer.android.com/studio) и открой
папку проекта. Студия сама скачает Gradle и зависимости, в первый раз это занимает
минут десять.

### 4. Включить отладку на часах

1. На часах: Настройки → О часах → Сведения о ПО → семь раз нажми на «Версия ПО».
2. Появится раздел «Параметры разработчика»: включи **«Отладка по ADB»** и
   **«Отладка по Wi-Fi»**.
3. Часы и компьютер должны быть в одной Wi-Fi сети.

### 5. Подключить часы и установить

В разделе «Отладка по Wi-Fi» на часах нажми «Сопряжение нового устройства», в Android
Studio открой **Device Manager → Pair Devices Using Wi-Fi** и введи код с часов.
Дальше выбери часы в списке устройств и нажми **Run**. Приложение появится в списке
приложений как **«Умный дом»**.

### Первый запуск

1. Открой приложение: на экране появится QR-код и короткий код.
2. Отсканируй QR камерой телефона (откроется `ya.ru/device`), войди в свой Яндекс и
   введи код с часов.
3. Через пару секунд часы сами перейдут к списку устройств.

## Решения, которые стоит знать

**Ключи не лежат в коде.** `CLIENT_ID` и `CLIENT_SECRET` читаются из `local.properties`
при сборке и попадают в приложение через `BuildConfig`. Так репозиторий можно держать
публичным, а у каждого, кто собирает проект, будет своё OAuth-приложение.

**Таймеры живут в системе, а не в приложении.** Wear OS агрессивно выгружает процессы,
поэтому отложенная задача внутри приложения ненадёжна. `AlarmManager` с
`setExactAndAllowWhileIdle` будит часы в нужную минуту, а команду отправляет
`BroadcastReceiver`, которому не нужен открытый интерфейс.

**Весь дом одним запросом.** Вместо отдельных запросов на каждую комнату и устройство
приложение берёт `GET /user/info` и строит всё из одного ответа. На часах с медленной
сетью через телефон это заметно быстрее.

**Без Retrofit и без тяжёлых библиотек.** Запросов всего четыре вида, поэтому хватает
тонкой обёртки над OkHttp и `org.json`. Меньше зависимостей, меньше размер APK.

## Ограничения

- **Камеры** API умного дома Яндекса не отдаёт как видеопоток, поэтому их в списке нет
  (или они без картинки).
- **NFC-пропуск** (эмуляция карты общежития) сделать нельзя, и это ограничение железа:
  часы не эмулируют MIFARE Classic и не видят карты 125 кГц.
- **«Не гасить экран»** заметно ест батарею, включай осознанно.

## Если что-то не работает

- **«Ошибка сети»**: проверь, что у часов есть интернет (Wi-Fi или через телефон).
- **После входа пустой список**: в OAuth-приложении должны быть отмечены оба доступа
  «Умный дом», а устройства привязаны к тому же аккаунту.
- **401/403 и снова экран входа**: токен отозван, просто войди заново.
- **Часы не видны в adb**: выключи и снова включи отладку по Wi-Fi, проверь, что часы и
  компьютер в одной сети.

## Что можно доделать

- Плитку (Tile) для Wear OS с избранными устройствами, чтобы не открывать приложение.
- Усложнение (complication) на циферблат: температура с датчика или статус света.
- Голосовые команды через ассистента часов.
- Кэш дома на часах, чтобы список появлялся мгновенно, а обновлялся в фоне.
